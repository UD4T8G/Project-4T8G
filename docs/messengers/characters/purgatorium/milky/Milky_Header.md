## sitaegeuk

* **[사자들](../../../core/messengers/Messengers_Header.md)의 [날개](../../../core/messengers/Messengers_Header.md#wings)**

  - 자신을 다른 좌표로 이동시킨다.

## fusion-core

* **냉각로**
  - 심장부에 장착되어 있는 동력원이다.
  - 밀키의 등에 있는 포트를 열어서 접근한다.
  - [홀스터](#holster)와 선형으로 연결한다.
  - 연결된 [홀스터](#holster)를 충전한다.
* **봉인**
  - 해제된 [오피스](#ophis)를 보관하여 비전투 형태로 전환한다.
* **해제**
  - 봉인된 [오피스](#ophis)를 풀어 전투 형태로 전환한다.

## ophis

* **밀키의 뱀**
  - 그 수가 무수히 많으며, 융합해서 거대화하거나 분열해서 축소화한다.
  - 적중된 모든 것에 무형을 가하여 냉동시킨다.
  - 참수해서 머리를 [멀티폴](#multipole)로 사용한다.
  - 참수해서 몸통을 [홀스터](#holster)로 사용한다.
  - 수복해서 소환수로 사용한다.

---

## holster

* **[오피스](#ophis)의 몸통**
  - [오피스](#ophis)의 몸통을 변형하여 사용한다.
  - 밀키의 신체에 고정된 채로 조준하고 공격한다.
* **부스터 샷**
  - 원거리 형태의 [모노폴](#multipole)을 장착하고 빠르게 사격하여 추진한다.
* **파라솔 컷**
  - 근거리 형태의 [모노폴](#multipole)을 장착하고 빠르게 회전시켜 공격한다.

---

## multipole

* **모노폴**
  - [오피스](#ophis)의 머리 하나를 변형하여 독립적으로 사용한다.
  - [홀스터](#holster)에 연결되어 있을 경우 자동으로 공격한다.
  - [홀스터](#holster)에서 머리를 꺼내는 동시에 공격한다.
  - 여러 대상을 동시에 제압할 수 있다.
* **바이폴**
  - [오피스](#ophis)의 머리 여러 개를 *Cis* 합체하여 사용한다.
  - 공격이 공명되어 성능이 높아지지만 효율이 낮아진다.
  - 병렬 합체 형태와 직렬 합체 형태가 존재한다.
* **다이폴**
  - [오피스](#ophis)의 머리 여러 개를 *Trans* 합체하여 사용한다.
  - 전방위로 공격하여 성능이 높아지지만 안정성이 낮아진다.
  - 아군 주변에서 반중력 회전 비행한다.
  - 적군 주변에서 반중력 회전 비행한다.

## mea-culpa

* **나의 크나큰 탓이로소이다**
  - 밀키의 모든 부상은 [융합로](#fusion-core)의 손상으로 이전된다.
  - [융합로](#fusion-core)가 손상되었을 경우 무형이 증가한다.
  - [융합로](#fusion-core)를 가동하는 [날개](../../../core/messengers/Messengers_Header.md#wings) 에너지가 부족할 경우 무형이 증가한다.
  - 무형이 증가할수록 속도가 증가하고 지속적으로 글리치를 일으킨다.
* **뱀이 저를 꾀어서 제가 따먹었습니다**
  - [오피스](#ophis)를 참수해서 사용하는 경우 [날개](../../../core/messengers/Messengers_Header.md#wings) 에너지가 지속적으로 감소한다.
  - [오피스](#ophis)를 수복해서 사용하는 경우 [날개](../../../core/messengers/Messengers_Header.md#wings) 에너지가 지속적으로 증가한다.
