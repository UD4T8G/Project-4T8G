# Boss Main

---

## characteristics

* *보스는 자색 포인트의 흑색 제복, 자색 벨트의 흑색 긴 바지, 자색 끈의 흑색 산달리온을 착용하고 있다.*
* *그는 전신이 몰아치는 흑색 공허 폭풍으로 구성되어 있으며, 자색 포인트의 번개로 안광을 표현하고 있다.*
  - *그는 태어나기 전부터 세상의 초등학문을 좋아했기에 철학적인 성격을 지니게 되었다.*
  - *그는 초등학문의 한계까지도 간파하고 있어 풍자적이고 해학적인 모습을 자주 보여준다.*
* *[아이기스](./Boss_Header.md#aegis)는 백색 아말테아의 가죽에 흑색 아에토스 디오스의 날개를 결합한 자색 포인트의 원형 방패이다.*
  - *보스는 그녀를 어머니처럼 여기지만, 무저갱에서의 불안정한 [날개](../../../core/messengers/Messengers_Header.md#wings) 각성은 그의 수명을 단축시킨다.*
* *[아스트라페](./Boss_Header.md#astrape)는 흑색 공허 폭풍을 두르고 있는 자색 포인트의 번개이다.*
  - *보스는 이것을 체내에 저장했다가 방출하지만, 이는 무저갱을 품는 것과도 같이 그의 수명을 단축시킨다.*
