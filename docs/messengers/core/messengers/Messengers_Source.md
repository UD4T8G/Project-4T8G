# Messengers Source

---

## concept

* 사자들은 다른 신이 아니라 새겨진 우상(Graven Image)으로 구현되었다.
  - 종교적 에피테트가 아니라 비평학적 사실을 바탕으로 구상되었다.
  - 천사나 악마보다는 베헤못과 리워야단에 가깝게 묘사된다.

---
